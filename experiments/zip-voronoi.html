Pop vs Soda by ZIP code and FSA

Each cell is the area closer to one US ZIP code or Canadian forward sortation area (FSA) than to any other in the same region. Each country (or each state and province) gets its own diagram, clipped to its own outline, so cells stop at the boundary. Colors mix the shares of responses like the main map's CMY scheme: yellow for pop, cyan for soda, magenta for coke, and darker for "other". Built from data/postal_counts.csv.
