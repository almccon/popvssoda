Pop vs Soda county bubbles

Each county gets up to four circles: pop, soda, coke and other, each with area proportional to the number of people who gave that answer. The circles start at the county's center and push each other apart, so crowded metro areas spread out into clusters while sparse regions keep lots of space. They bubble up from the south, each growing to full size over 5 seconds while the layout makes room. Size the circles by the number of responses, or by the county's population (2010 census) split between the four circles in proportion to how people there answered. Or draw one circle per county, colored like the main map: yellow for pop, cyan for soda, magenta for coke, mixed in proportion and darker for "other". With state outlines on, each state starts as its border, which swells and shifts with the bubbles so you can still tell which state each came from.
