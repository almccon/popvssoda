# Archive

Older versions of the Pop vs Soda page, kept for reference:

- `indexold2.html`: the original page with hand-drawn GIF maps.
- `index.static.html`: the static PNG map page, including the media coverage list.
- `style.css`: the stylesheet both of those pages (and the pre-2026 `index.html`) used.

They still point to `../images/`. They load jQuery over plain `http://`, so their
tabs may not work in a modern browser.
